05

Copy & paste

Working examples. Plain markup.

Pick a content type to see the HTML or JavaScript that opens it. Links with the same data-razorbox value become one gallery.

Gallery / HTML
<!-- Same data-razorbox value = same gallery -->
<a href="/images/01.jpg" data-razorbox="trip"
   data-caption="Mountain view">
  <img src="/images/01-thumb.jpg" alt="Mountain view">
</a>
<a href="/images/02.jpg" data-razorbox="trip"
   data-caption="At the coast">
  <img src="/images/02-thumb.jpg" alt="At the coast">
</a>
HTML5 video / HTML
<!-- Autoplay is requested; browsers may block sound -->
<a href="/videos/intro.mp4"
   data-razorbox="videos" data-type="video"
   data-poster="/images/poster.jpg"
   data-caption="An HTML5 video">
  Play video
</a>
YouTube / HTML
<!-- Privacy Enhanced Mode: youtube-nocookie.com is enforced by default -->
<a href="https://www.youtube.com/watch?v=C9f88SVNHxA"
   data-razorbox="videos"
   data-caption="YouTube video">
  Open YouTube video
</a>
Vimeo / HTML
<!-- Vimeo player URL includes dnt=1 by default -->
<a href="https://vimeo.com/155404383"
   data-razorbox="videos"
   data-caption="Vimeo video">
  Open Vimeo video
</a>
Inline HTML / HTML
<!-- Open a real DOM element and restore on close -->
<a href="#contact-form" data-razorbox="content"
   data-type="html">Open contact form</a>

<div id="contact-form" hidden>
  <h2>Get in touch</h2>
  <input type="email" placeholder="Your email">
  <button type="button">Send</button>
</div>
Iframe / HTML
<!-- The destination must permit iframe embedding -->
<a href="/contact.html" data-razorbox="content"
   data-type="iframe"
   data-caption="Contact page">
  Open contact page
</a>
Google Maps / HTML
<!-- Standard Google Maps links are auto-recognized. -->
<a href="https://www.google.com/maps/search/?api=1&amp;query=Empire+State+Building&amp;query_place_id=ChIJaXQRs6lZwokRY6EFpJnhNNE"
   data-razorbox="places" data-type="map"
   data-caption="Empire State Building">
  Open Google Maps
</a>

<!-- For a stable production embed, supply mapApiKey in JS
     or data-embed-src with a URL from Maps > Share > Embed a map. -->
PDF / HTML
<!-- A PDF URL ending with .pdf is recognized automatically. -->
<a href="/documents/brochure.pdf"
   data-razorbox="documents" data-caption="Our brochure">
  View PDF
</a>

<!-- Also supports data-type="pdf" for URLs without .pdf suffix. -->
JavaScript / main.js
import razorbox from '@rafu1987/razorbox'
import '@rafu1987/razorbox/css'

razorbox.bind('[data-razorbox]', {
  transition: 'fade', // or 'slide'
  thumbnails: true,
  thumbsOpen: false,
  videoAutoplay: true,
  videoMuted: false,
  videoPrivacy: true,
  wheelZoom: true, // Mouse wheel and Mac trackpad pinch
  maxZoom: 8, // Gesture zoom; toolbar uses 2x
  theme: 'dark',
  locale: 'auto' // Uses page language first
})

06

Spec sheet

All the essentials. Zero bloat.

No plugins to assemble. Everything here ships in one module and one stylesheet, and every feature can be switched off.

Zoom & pan
Wheel, trackpad pinch and touch pinch up to 8×, anchored to the pointer. Drag to pan; the zoom button returns to fit.
Slideshow
Play and pause from the toolbar or with Space, with your own interval.
Thumbnail rail
A bottom strip you can drag, scroll and toggle with T.
Fullscreen
The native Fullscreen API, on the toolbar and on F.
Accessibility
A labelled modal dialog with a focus trap, focus restore, a live region for slide changes, and axe-core checks in CI.
Privacy
YouTube via youtube-nocookie.com and Vimeo with dnt=1 by default.
Localization
English, German and French, picked from <html lang>. Override any label.
Theming
Dark, light or system, plus --rb-* custom properties for colors and sizes.
Separate CSS
One ES module and one stylesheet. Nothing is injected at runtime, so strict CSPs stay happy.

07

Get started

Two imports. Develop.

Install the package, import the module and its stylesheet, and bind it to your links.

  1. Install with Yarn or npm. The package is ESM-only and ships TypeScript types.
  2. Import the module and its stylesheet. Your bundler takes care of the rest.
  3. Bind it to links with data-razorbox. Links added later work too.
Full API reference →
main.js
import razorbox from '@rafu1987/razorbox'
import '@rafu1987/razorbox/css'

razorbox.bind('[data-razorbox]', {
  thumbnails: true,
  transition: 'fade',
  slideshow: true,
  wheelZoom: true,
  maxZoom: 8,
  videoAutoplay: true,
  videoMuted: false,
  theme: 'dark',
  locale: 'auto'
})
